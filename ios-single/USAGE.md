# SingleCast 使用说明

> 适用版本：0.3（App 内已内置三步引导，本文是加长版，含每个失败分支的判断）

## 你要先理解的一件事

SingleCast 干的是**把画面塞进九号仪表当外接显示器**，它不改车、不刷固件，只往车机的一个 UDP 端口发视频包。所以整条链路上有**两个必须同时成立的前提**：

1. **车机自己开着门**（进入投屏接收状态）；
2. **你的手机连在车机自己开的热点上**（否则包根本到不了它）。

这两个不成立，App 里再怎么点都不会有画面——不是 App 的问题。

---

## 三步走

### 第 1 步：让车机进入「投屏接收」

- 车机（仪表）上要有一个**投屏 / 屏幕镜像 / 接收**的入口并点进去，各家固件位置不一样：常见在车机设置里，或者从九号出行 App 的投屏导航入口进一次再退出。
- 进入后，车机会**自己开一个 Wi-Fi 热点**，SSID 通常带车架号或型号。
- 提示：**退回车机主界面往往就退出接收态**，所以下一步要快。

### 第 2 步：手机连上这个热点

- 走系统「设置 → Wi-Fi」，连车机那个热点。
- iOS 会提示「无互联网连接」，选**保持连接**。
- 首次连上后打开 SingleCast，如果弹「是否允许查找并连接本地网络设备」，**必须点允许**（不允许的话所有 UDP 包会被系统静默丢掉，表现就是帧数在涨但车机黑屏）。
- 回到 App，看「第 2 步 · 网络检查」里显示的本机 IP：
  - `192.168.1.x` / `192.168.169.x` → ✅ 网段对，继续；
  - 其他（比如 `10.x`、`172.x`）→ 你连的不是车机热点，回到系统设置换 Wi-Fi。

### 第 3 步：确认车机地址，先推测试图

- 点「**探测**」。App 会向 `192.168.1.1`、`192.168.169.1`、你当前网段的 `.1` 各发一个 20 字节心跳（UDP 5013），谁回 `85 CC …` 谁就是车机。
- 探测结果显示成一行：`✅ 192.168.1.1  12 ms · 20 字节`，**点一下就会填进输入框**。
- 探测不到就手动填。已知两种网关：`192.168.1.1`、`192.168.169.1`。
- 填好后点「**推送测试图（先验证通路）**」。

**车机上应该立刻出现**：深色底 + 底部七色彩条 + 一个左右移动的白块 + `FRAME 000123 848x480` 帧号在跳。

画面出来 = 协议、编码、socket、网络全部正确。**这一步通了，才值得点「启动 CarPlay 接收」。**

## 两个按钮分别是什么

| 按钮 | 做什么 | 什么时候用 |
|---|---|---|
| 推送测试图 | 自己画彩条 → VideoToolbox 编码 → 20 字节私有头 → UDP 5012 | **永远先点这个**。它把「CarPlay」这个变量摘掉，用来验证链路 |
| 启动 CarPlay 接收 | 用包内 MFi 证书造虚拟配件 → iAP2 认证 → RTSP → 解码 → 重编码 → 推车机 | 测试图能出画面后，再点它 |

为什么要这样分：CarPlay 那一层依赖 iOS 私有接口 `ACCTransportClient`，**自签 App 可能根本拿不到权限**。先跑测试图，出问题时你能立刻分清是「链路坏」还是「CarPlay 拿不到权限」。

## 常见失败与对应动作

| 现象 | 大概率原因 | 怎么办 |
|---|---|---|
| 车机完全没反应，帧数在涨 | 车机没进接收态 / IP 不对 / 九号出行占着端口 / 没给本地网络权限 | 依次排查：进接收态 → 用「探测」拿 IP → 杀掉九号出行 App → 设置 → SingleCast → 本地网络 |
| 「探测」一个都探不到 | 不在车机热点上 / 车机没开门 | 看本机 IP 是否 `192.168.1.x`；车机上重新进一次接收态 |
| 车机闪一下就黑 / 花屏 | 分片或码率被丢 | 把日志复制给我，先降码率再试 |
| CarPlay 模式秒退 / 报错 | 私有接口权限 | 日志第一行有 `ACCTransportClient classFound=…`；`false` 就是没权限，这条路要换方案 |
| App 切到后台就停 | iOS 后台策略 | 保持 App 在前台；骑行时把手机架起来 |

日志面板右下角有「**复制日志**」按钮，出问题直接复制发我，比描述现象准得多。

## 现在还没做到的部分（如实说明）

- **CarPlay 接收仍是实验态**：代码全在、能在 CI 编过，但 iAP2 消息 ID 与 RTSP 通道细节是公开研究值，第一次真机跑才会暴露具体卡点。日志已按环节埋点。
- **不是"一键连车机"**：iOS 不允许 App 自己连 Wi-Fi（需要 `NEHotspotConfiguration` 企业级 entitlement，自签拿不到），所以第 2 步必须手动。
- **受保护内容黑屏**：CarPlay 侧的 DRM 内容由系统控制，`SDK` 层拿不到。

---

## 一句话流程

> 车机开接收态 → 手机连它热点 → App 里点「探测」→ 点「推送测试图」→ 看到彩条 → 再试 CarPlay。
